# TubeFlow — Free YouTube Creator Studio

TubeFlow is a free, local-first workspace for turning a video idea into a practical YouTube content plan. It generates a script outline, title suggestions, a description, tags, and a thumbnail concept from your brief.

## Run it

No install, account, API key, or paid service is required. Download or clone this repository and open `index.html` in a modern browser. For local hosting, you can run `python3 -m http.server 8000` from the project directory and visit `http://localhost:8000`.

## Features

- Create a video brief with topic, niche, audience, tone, and target length.
- Generate a structured outline and starter SEO copy in the browser.
- Save projects to this browser's local storage.
- Download a complete video plan as a Markdown file.
- Responsive layout for desktop and mobile.

## What “free” means here

All content suggestions are produced with built-in templates in your browser. TubeFlow does not call an AI provider, require an API key, or send your brief to a server. Generated copy is a starting point, not a guarantee of search ranking, views, or accuracy. Review and personalize it before publishing.

Saved projects remain in the current browser on the current device. Clearing browser data removes them. Use the download button to keep a portable copy.

## YouTube publishing

TubeFlow helps you plan content but does not automatically upload or publish videos. YouTube upload automation requires authorizing a Google account through the official YouTube Data API and complying with YouTube's terms and API policies. This version deliberately requires no credentials and leaves publishing under your control.

TubeFlow is an independent tool and is not affiliated with YouTube or Google.
